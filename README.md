# 🍣 Sushis Waza – Serveur Web

Serveur web Python pour l'application **Sushis Waza**, gérant les comandes de sushis sur Paris.

---
## 🛠️ Prérequis

- Python 3.x
- [Matplotlib](https://matplotlib.org/)
 ou
```bash
pip install matplotlib
```

---

## Lancement du serveur 

```bash
python sushis_waza_serveur.py
```

Le serveur démarre sur le port **8081** :

```
Serveur lancé sur le port 8081
```

Interface disponible sur : [http://localhost:8081](http://localhost:8081)

---

## 📁 Structure du projet

```
projet/
├── sushis_waza_serveur.py   # Serveur principal
└── client/                  # Fichiers statiques (HTML, CSS, JS)
```

---

## ⚙️ Configuration

Le port est modifiable dans `sushis_waza_serveur.py` :

```python
port_serveur = 8081
```
